# Robot Monitor

このフォルダの内容をGitHub Pagesの公開元へ配置（index.htmlをルート）。HTTPSでWeb Bluetooth対応ブラウザから接続します。
実運用main_controlと組み合わせ、CH32電源情報・実測100ms最小最大グラフ・最新先頭ログを表示します。
電源の遮断/再投入/緊急停止と、0x720のQDD基板のキャリブレーションに対応。
回生リレーはONで抵抗遮断、OFFで抵抗導通。ESTOPは主リレー投入後のみ判定し、対象外を正常と表示しません。
QDD基板の生存・エラー・リミット入力・原点出し完了軸と、QDD各軸の状態/エラーを表示。
位置・速度・電流・トルクなど未送信の計測は「—」、個別モーター操作は無効。STS行は削除済み。
?demo=1は電源データの表示デモ。実機命令は送りません。

キャリブレーション更新版：親main_control・子pico_armも同時に更新してください。
接続表示と基板エラーを分け、エラーを日本語で説明します。開始ボタンには操作できない理由を表示します。
基板エラーマスクでの一律禁止を外しました。操作接続、電源正常、子の生存通知、重複実行の有無を確認します。
QDD1→QDD2→QDD3→DCの進行段階を表示し、動作手順は操作画面で展開できます。
