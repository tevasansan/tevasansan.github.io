キャリブレーションの動作
  1. 全QDDを停止し、速度0・速度制御・電流上限を設定。
  2. QDD 1 → QDD 2 → QDD 3 → DCの順に、1軸ずつリミットへ移動。
  3. 開始時にリミットがONなら、いったん逆方向へ離脱してから接近。
  4. リミットがONになったら停止し、30ms安定したことを確認して次の軸へ。
  5. 全軸を停止し、QDDの現在位置を原点として記録。DCはリミット到達を記録。

QDD：0.05回転/秒、電流上限2.5A。DC：10rpm。離脱は最大3秒、接近は各軸最大15秒。探索方向は子基板のArmConfig.hで指定します。途中で止める場合は緊急停止を押してください。
